SVD means Singular Value Decomposition.

In this project, it is used after TF-IDF to compress high-dimensional text vectors into a smaller semantic-ish space.

Roughly:

huge sparse TF-IDF text vector -> SVD -> smaller dense vector
Why use it here:

TF-IDF creates thousands of dimensions.
SVD keeps the strongest patterns of variation.
This makes clustering and 2D visualization less noisy and easier to compute.
So in the summary, TF-IDF -> TruncatedSVD -> PCA(2D) means: turn text into word-feature vectors, compress them, then project to 2D for plotting.

AUC means Area Under the Curve.

Here it is not medical ROC-AUC. It means the average value of a trajectory curve over time.

For example, best_alignment_auc tracks the best source alignment seen so far as proposals arrive:

proposal 1: best so far = 0.40
proposal 2: best so far = 0.55
proposal 3: best so far = 0.55
proposal 4: best so far = 0.70

best_alignment_auc = mean(0.40, 0.55, 0.55, 0.70)
Higher AUC means the method found good grounded proposals earlier and kept that advantage.
